Section 01

What this system does

Four capabilities, applied to the upgrader from commissioning onward.

01
Sets the most profitable number of passes, before each batch runs
Current oil sale prices are built into the profit calculation, so each charge is processed to the point where margin is greatest — rather than to a fixed recipe that ignores what the product is worth today.
02
Shows the operator how far a batch has been upgraded, live
An instrument already fitted to the skid becomes a running indication of progress. Laboratory work is needed once, during commissioning, to calibrate it — not batch by batch afterwards.
03
Works backwards from a target you set
Data gathered from the first day of operation means an API target can be named, and the system can then specify the settings and pass count needed to reach it efficiently.
04
Builds the record that makes improvement scientific
Every batch is logged and every instrument watched for drift, so changes to the process are tested against evidence rather than argued from opinion.
Section 02

It already understands the machine

A single working session was spent reading everything available about the unit and building a structured engineering model of it.

The starting material was four documents: a research proposal, a technical report, a technical presentation, and the electrical construction drawings. None contained a process flow diagram or P&ID for the machine being built. The process was reconstructed instead from the instrument tag numbering inside the electrical package — the tag sequence encodes the flow path, and the control system descriptions name every major item of equipment.

The recycle branch is the heart of the process. A charge circulates through steps 2 to 5 repeatedly until it meets specification, which means the number of passes — not the flow rate — is the primary operating variable, and the one that most directly determines both product value and throughput.
And this is the floor, not the ceiling

That model was built from paper alone. A number of ordinary questions about the unit remain open — equipment ratings, exactly what some instruments measure, and what the incoming oil actually looks like. Each one answered sharpens the model, and in practice each tends to surface further points where the process can be improved. Understanding and capability grow together.

Section 03

Where production is currently left on the table

The unit is built around a premise: each pass through the cavitation device upgrades the oil further, so a charge is recirculated until it meets specification.

Every pass also burns energy, occupies the machine and consumes equipment life. If the premise holds, more passes means better oil and less of it. How much each pass actually delivers on this feedstock has never been measured — and that measurement is the first thing this work produces.

Illustrative, not measured. The shape is characteristic of this kind of process — value rises with diminishing returns while cost rises steadily, so margin peaks and then falls. Where the peak sits for this machine on this feedstock is what the commissioning work establishes.

Short of the peak, oil leaves the plant worth less than it could have been. Past it, machine time and power are spent producing quality that does not earn its cost.

The peak is not a fixed setting. It moves — and a unit run on habit cannot track a target that moves.

How the optimum is calculated

Not a principle — a model with defined inputs, run before a batch starts to give the operator a pass count for that charge at current prices.

margin per batch =
  (volume out × price at achieved quality)
  − (passes × energy and time per pass)

optimum = the pass count where the next pass stops paying for itself

Three of the five inputs come from what the business already has — your sales terms, whether feed is waiting, and the installed motor ratings combined with the batch cycle time the flow meters record. The remaining two come from lab samples taken while the unit is being commissioned.

Making progress visible on the floor

Upgraded crude is typically priced on gravity, and the skid carries no instrument that measures gravity. It does measure viscosity, continuously, at the cavitation outlet.

Sampling through the first few batches establishes the relationship between the two for your feed. From then on the live viscosity reading stands in for gravity, and an instrument already bolted to the machine tells the operator how far the charge has come and how close it is to the point where further processing stops paying. The laboratory work is a one-time calibration, not an ongoing cost.

Section 04

What it delivers, over time

The value is not a one-off analysis. It is a cycle that tightens each time it runs.

Step 01
Measure
Every batch logged in full — conditions, pass count, energy, outcome.
Step 02
Find the pattern
Which variables actually moved the result, separated from noise.
Step 03
Change one thing
A single deliberate adjustment, with the expected result written down first.
Step 04
Compare
Outcome against prediction. Where they differ, the model was wrong and improves.
↺  each pass through the loop makes the next recommendation sharper

Most units never close this loop. They accumulate operating data for years without a structure that turns it into knowledge, and improvement stays a matter of opinion.

The difference between a machine that has run for a year and a machine that has learned for a year is entirely in whether this loop was running.

First months of operation
Establish what the machine actually does
  • A characterised baseline — the documented reference every future change is measured against. Without it, no improvement can be proven, only asserted.
  • The uplift-per-pass curve — how much each additional cycle genuinely delivers, and where the returns flatten.
  • Progress visible on the floor, through the viscosity relationship described above.
  • The bottleneck identified — where the batch cycle loses time and which step limits throughput.
  • Instrument integrity confirmed — drift and faults caught before they corrupt months of conclusions.
Ongoing operation
Run at the most profitable point, every batch
  • Pass count set against margin, not habit — computed before the batch runs, from measured data and the price the product will fetch.
  • Treatment matched to the oil actually arriving, rather than fixed to an average that may rarely occur.
  • Throughput raised by removing the limiting step, identified from cycle data rather than impression.
  • Predictive maintenance. Cavitation is inherently erosive; tracking device condition converts unplanned failures into scheduled work.
  • Autonomous monitoring — routine analysis running against live data, surfacing only what needs a decision.
As the operation grows
Make the result repeatable
  • A documented, transferable design basis. A machine cannot be replicated or supported from a design that exists only as one physical object. Assembling that record is a direct output of the work above.
  • Performance evidence that survives scrutiny — measured, sourced and reproducible, so what is presented to a partner or lender holds up when examined.
  • A known performance envelope across feedstocks, so what can be promised is known rather than hoped.
  • Standardised commissioning, so each new unit is brought online against a proven protocol instead of being worked out again.
Beyond the upgrader

The method is not specific to this machine. Any operation where a controllable variable trades against cost — and where the right setting moves with market conditions — can be modelled the same way. The upgrader is the first application, not the only one.
